Módulo Gestión de Compras - Farmacias Galeno



Este repositorio contiene la especificación, diseño arquitectónico y contrato de API

para la modernización del módulo gestión de compras Farmacias Galeno, migrando de un sistema

monolítico legado en C# .NET Framework 4.5 a una arquitectura limpia basada en C# .NET 8,

OpenAPI 3.0 y estrategia de caché con Redis.





Estructura del Repositorio

* informe/`: Documento PDF principal con el informe consolidado.
* docs/legacy/`: Diagramas del sistema monolítico heredado.
* docs/api/`: Especificación OpenAPI 3.0 (Swagger) y capturas de validación.
* docs/c4/`: Planos técnicos bajo el modelo de arquitectura C4 (Niveles 1, 2 y 3).
* docs/database/`: Diagrama de persistencia y script ejecutable DDL (SQL Server).
* docs/cache/`: Diagrama y especificación de la estrategia de caché con Redis.
* docs/evidence/`: Capturas de pruebas y validaciones.
